# Game Design Document

## Genre

2D top-down roguelike survival action game.

## Core Loop

1. Player starts a run.
2. Enemies spawn.
3. Player defeats enemies.
4. Enemies drop EXP.
5. Player collects EXP.
6. Player levels up during the run.
7. Player chooses temporary upgrades.
8. Player dies or clears the stage.
9. Player receives permanent resource.
10. Player buys permanent upgrades.
11. Player starts the next run stronger.

## EXP

- Earned during a run.
- Used for run-based level up.
- Resets after the run ends.
- Not saved.

## Permanent Resource

- Earned after a run.
- Saved permanently.
- Used for permanent upgrades.

## MVP Features

- Player movement
- Enemy chasing
- Auto attack
- Projectile damage
- EXP orb
- Level-up UI
- Run result screen
- Permanent resource
- Save/load
- Permanent upgrade menu
